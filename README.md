### 20.09.2026 — Юніт 1: персонаж і рух
Сьогодні я створив першу сцену MainScene, налаштував тайлмап підлоги та створив скрипт PlayerController. 
Найбільше часу пішло на правильне налаштування Input System, оскільки потрібно було створити два композити для WASD і стрілок, а також додати прив'язку для геймпада. 
Також виникла невелика проблема зі щілинами між тайлами, але зміна Pixels Per Unit на 64 це виправила. 
Завдяки лабораторній роботі я розібрався, чому важливий Time.deltaTime: без нього швидкість персонажа повністю залежить від fps комп'ютера.

### 07.10.2026 — Лабораторна робота №3: колізії водойми та публікація на GitHub
Сьогодні я налаштував інтерактивне середовище для водойми та підключив проєкт до системи контролю версій Git.

Для побудови водойми нарізав спрайт FloorWaterRoundCorners на 9 частин (сітка 3×3 в Sprite Editor) та створив з них відповідні тайли води. Налаштував параметр Default Collider = Grid для всіх частин водойми, завдяки чому персонаж чітко взаємодіє з її межами по всьому периметру.

Також створив і налаштував репозиторій robot-repair-Gavryliuk. За допомогою GitHub Desktop завантажив проєкт (папки Assets та ProjectSettings) на GitHub та відправив фінальний коміт.
